# 🌡️ Temperature Monitoring System (PCB Design)

## 📌 Project Overview
This project is a Temperature Monitoring System designed and implemented using analog components and a custom PCB. The system measures temperature using a sensor and converts it into a readable electrical signal.

The entire circuit has been designed, simulated, and fabricated as a PCB for reliable and compact operation.

---

## 🎯 Objectives
- To measure temperature using a sensor (LM35)
- To design a stable analog signal processing circuit
- To implement the design on a custom PCB
- To ensure accurate and continuous monitoring

---

## 🧰 Components Used
- LM35 Temperature Sensor
- Op-Amp (e.g., LM358 / IC 741)
- Resistors and Capacitors
- Power Supply Unit
- PCB Board

---

## ⚙️ Working Principle
- The LM35 sensor outputs a voltage proportional to temperature (10mV/°C).
- The signal is conditioned using an operational amplifier.
- The processed output can be observed using a voltmeter or further interfaced with other modules.

---

## 🖥️ PCB Design
- Designed using KiCad
- Includes schematic and PCB layout files
- Proper routing and grounding techniques followed
- Compact and efficient design

---

## 📂 Project Files
The repository includes:
- Schematic design files
- PCB layout files
- Gerber files (for fabrication)
- Bill of Materials (BOM)
- Project report (if included)

---

## 🚀 How to Use
1. Fabricate the PCB using the provided Gerber files
2. Assemble all components as per the schematic
3. Provide power supply
4. Measure output voltage corresponding to temperature

---

## 📊 Applications
- Industrial temperature monitoring
- Environmental sensing
- Embedded system projects
